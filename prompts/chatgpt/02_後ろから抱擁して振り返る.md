# 02 後ろから抱擁して振り返る

- 用途：ChatGPT画像生成
- 種類：成人女性2人、ロマンティックなポートレート
- 参照：IMAGE 1 = 画面右手前、IMAGE 2 = 画面左奥

## プロンプト

添付した2枚の人物画像を参照し、成人女性2人のフォトリアルな画像を生成してください。

**人物の割り当て**
- IMAGE 1：完成画像の画面右手前の女性
- IMAGE 2：完成画像の画面左奥の女性

それぞれの顔立ち、髪型、髪色、特徴的なアクセサリーを忠実に再現してください。元画像のポーズ、衣装、背景は引き継がないでください。

**構図**

IMAGE 1の女性が手前に立ち、IMAGE 2の女性がその背後から両腕を腰に回して抱きしめています。

手前の女性は左肩越しに顔を振り返り、後ろの女性が顔を近づけて優しくキスをしています。

2人の顔は斜め方向から見え、横顔と表情が分かるようにしてください。

**撮影条件**

カメラは右斜め前方。腰から上を収めた縦長構図。自然な室内光。

2人の身体の前後関係、腕のつながり、手の位置が明確になるようにしてください。服装は落ち着いたカジュアルスタイル。
