# プロンプト集

ChatGPT・Grok・ComfyUIなどで使用する画像・動画生成プロンプトの保管庫です。

## 使い方

各Markdownファイルを開き、「プロンプト」以下の本文をコピーして使います。参照画像を指定する形式では、各ファイルの `IMAGE 1` / `IMAGE 2` の割り当てを確認してください。

別のChatGPTチャットから呼び出す際は、このリポジトリのURL（https://github.com/numahikodaze-creator/-）と、構図名またはファイルのパスを指定してください。GitHubへのアクセスが使えるチャットで内容を取得できます。会話のたびに自動的に読み込まれることを保証するものではありません。

## 管理方針

- プロンプトは、種類・用途別のMarkdownファイルとして保存します。
- 既存ファイルの改稿は、元の内容を確認してから行います。
- 新しい案は、未登録のものとして別ファイルに追加できます。
- 参照人物の固有名に依存せず、再利用できる記述を基本とします。
